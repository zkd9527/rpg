## 1. 项目概述

### 1.1 项目简介
本项目是一款基于Unity引擎开发的2D横版银河恶魔城（Metroidvania）风格游戏。游戏融合了动作战斗、角色成长、探索解谜等核心元素，采用模块化架构设计，实现了完整的游戏功能框架。

### 1.2 核心特性
- **完整的角色控制系统**：支持移动、跳跃、冲刺、墙跳、二段跳等复杂操作
- **丰富的战斗系统**：包含多种攻击方式、技能系统、状态效果
- **深度的RPG元素**：属性系统、装备系统、技能树系统
- **完善的存档机制**：支持游戏进度和设置的持久化存储
- **多样的敌人AI**：不同类型敌人具有独特的行为模式

### 1.3 技术栈
- **游戏引擎**：Unity 2021+
- **编程语言**：C#
- **架构模式**：状态机模式、单例模式、组件化设计
- **数据存储**：JSON序列化、ScriptableObject

```
├── PlayerWallJumpState (墙跳状态)
```

```csharp
public class PlayerMoveState : PlayerGroundedState

    {
        base.Update();

        {
            stateMachine.ChangeState(player.idleState);
        }
    }
```

**示例 - 冲刺状态：**
```csharp
public class PlayerDashState : PlayerState
{
    public override void Enter()
    {
        base.Enter();
        stateTimer = player.dashDuration;
        player.stats.BecomeInvincible(true); // 冲刺时无敌
    }
    
    public override void Update()
    {
        player.SetVelocity(player.dashSpeed * player.dashDirection, 0);
        player.fx.CreateAfterimage(); // 创建残影
        
        if (stateTimer < 0)
        {
            stateMachine.ChangeState(player.idleState);
        }
    }
    
    public override void Exit()
    {
        player.stats.BecomeInvincible(false);
    }
}
```

#### 5.2.3 伤害计算公式
```
总闪避 = 闪避 + 敏捷 + [攻击者麻痹效果]
总伤害 = (伤害 + 力量) × [总暴击伤害] - 目标.护甲 × [目标冰冻效果]
总暴击率 = 暴击率 + 敏捷
总暴击伤害 = 暴击伤害 + 力量
总魔法伤害 = (火焰伤害 + 冰霜伤害 + 雷电伤害 + 智力) - (目标.魔抗 + 3 × 目标.智力)
```

#### 5.2.4 伤害计算实现
```csharp
public virtual void DoDamge(CharacterStats _targetStats)
{
    if (_targetStats.isInvincible) return;
    if (TargetCanEvadeThisAttack(_targetStats)) return;
    
    int _totalDamage = damage.GetValue() + strength.GetValue();
    
    bool crit = CanCrit();
    if (crit)
    {
        _totalDamage = CalculatCritDamage(_totalDamage);
    }
    
    _totalDamage = CheckTargetArmor(_targetStats, _totalDamage);
    _totalDamage = CheckTargetVulnerability(_targetStats, _totalDamage);
    
    _targetStats.TakeDamage(_totalDamage, transform, _targetStats.transform, crit);
}
```

```csharp
public void ApplyAilments(bool _ignite, bool _chill, bool _shock)
{
    // 燃烧：持续伤害
    if (_ignite && canApplyIgnite)
    {
        isIgnited = _ignite;
        ignitedAilmentTimer = igniteDuration.GetValue();
        StartCoroutine(fx.EnableIgniteFXForTime_Coroutine(ignitedAilmentTimer));
    }
    
    // 冰冻：减速和减甲
    if (_chill && canApplyChill)
    {
        isChilled = _chill;
        chilledAilmentTimer = chillDuration.GetValue();
        GetComponent<Entity>()?.SlowSpeedBy(0.2f, chillDuration.GetValue());
    }
    
    // 麻痹：增加闪避
    if (_shock && canApplyShock)
    {
        ApplyShockAilment(_shock);
    }
}
```

```csharp
public class ParallaxBackground : MonoBehaviour
{
    [SerializeField] private float parallaxEffect;  // 视差效果强度
    
    private void Update()
    {
        float BGPositionOffset = cam.transform.position.x * (1 - parallaxEffect);
        float distanceToMove = cam.transform.position.x * parallaxEffect;
        
        transform.position = new Vector3(xPosition + distanceToMove, transform.position.y);
        
        // 循环背景
        if (BGPositionOffset > xPosition + length)
            xPosition += length;
        else if (BGPositionOffset < xPosition - length)
            xPosition -= length;
    }
}
```

```csharp
public void PlaySFX(int _sfxIndex, Transform _sfxSourceTransform)
{
    // 防止重复播放
    if (sfx[_sfxIndex].isPlaying) return;
    
    // 距离检测
    if (Vector2.Distance(player.transform.position, _sfxSourceTransform.position) > sfxMinHearableDistance)
        return;
    
    // 随机音调变化
    sfx[_sfxIndex].pitch = Random.Range(0.85f, 1.15f);
    sfx[_sfxIndex].Play();
}
```
